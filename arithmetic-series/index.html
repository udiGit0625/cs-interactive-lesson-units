שלב 1

הסכום של סדרה חשבונית כללית

בסדרה חשבונית ההפרש בין כל שני איברים סמוכים הוא קבוע. נסמן את האיבר הראשון ב־a₁, את ההפרש ב־d, ואת מספר האיברים ב־n.

איברי הסדרה

Sₙ = n(a₁ + aₙ)/2

הרעיון: מחברים את האיבר הראשון עם האחרון, השני עם הלפני־אחרון וכן הלאה. סכום כל זוג שווה.

במילים: סכום סדרה חשבונית הוא מכפלת מחצית מספר האיברים בסכום האיבר הראשון והאיבר האחרון בסדרה.

שלב 2

סכום המספרים מ־1 עד n

בסדרה זו: איבר ראשון a₁ = 1, איבר אחרון aₙ = n, מספר האיברים n.

1 + 2 + ... + n = n(n+1)/2

זוגות בעלי אותו סכום

שלב 3

סכום המספרים מ־0 עד n−1

בסדרה זו: איבר ראשון a₁ = 0, איבר אחרון aₙ = n−1, מספר האיברים n.

0 + 1 + ... + (n−1) = n(n−1)/2

אפשר לחשב על ידי הפחתת n מהסכום 1+2+...+n:

n(n+1)/2 − n = n(n−1)/2
שלב 4

המחשה בטבלה ריבועית

טבלה בגודל n × n מאפשרת לראות את שני הסכומים: כולל האלכסון מקבלים 1+2+...+n; מתחת לאלכסון בלבד מקבלים 0+1+...+(n−1).

החליפו בין שתי האפשרויות, הסתכלו על מספר התאים בכל שורה ונסו להגיע לנוסחה.

כחול: תא נספר. מסגרת כתומה: תא אלכסון. המספרים ליד השורות מציינים כמה תאים כחולים יש בכל שורה.

שלב 5

מחברים את הרעיון לחישוב יעילות ב־C#

בניתוח יעילות מזהים תחילה את הצעד הבסיסי — הפעולה שאת מספר ביצועיה אנו סופרים. מן הספירה מסיקים את סדר הגודל של פונקציית זמן הריצה, ולבסוף רושמים את הסיבוכיות בסימון O.

דוגמה א׳: 1 עד n

int count = 0;
for (int i = 1; i <= n; i++)
{
    for (int j = 1; j <= i; j++)
    {
        count++;
    }
}
1+2+...+n = n(n+1)/2

מספר ביצועי הצעד הבסיסי הוא בדיוק n(n+1)/2. מספר זה הוא מסדר גודל ריבועי, ולכן סיבוכיות זמן הריצה היא O(n²).

דוגמה ב׳: 0 עד n−1

int count = 0;
for (int i = 0; i < n; i++)
{
    for (int j = 0; j < i; j++)
    {
        count++;
    }
}
0+1+...+(n−1) = n(n−1)/2

מספר ביצועי הצעד הבסיסי הוא בדיוק n(n−1)/2. מספר זה הוא מסדר גודל ריבועי, ולכן סיבוכיות זמן הריצה היא O(n²).

הבחנה בין הצעד הבסיסי לבין פונקציית זמן הריצה: בדוגמאות ספרנו את מספר ביצועי הצעד הבסיסי בלבד, ולא את פונקציית זמן הריצה. לצורך חישוב פונקציית זמן הריצה המדויקת צריך להביא בחשבון גם את שאר ההוראות (אתחולים, בדיקות תנאי והגדלות מונים), בהתאם לכללי הספירה שנקבעו. בשתי הדוגמאות הן אינן משנות את סדר הגודל: O(n²).

int n = mat.GetLength(0);
int sum = 0;
for (int i = 0; i < n; i++)
{
    for (int j = 0; j < i; j++)
    {
        sum = sum + mat[i, j];
    }
}
Console.WriteLine(sum);

הצגת פתרון

הצעד הבסיסי הוא sum = sum + mat[i, j]. עבור i=0 הוא אינו מתבצע; עבור i=1 הוא מתבצע פעם אחת, וכן הלאה, עד i=n−1 שבו הוא מתבצע n−1 פעמים. לכן מספר הביצועים של הצעד הבסיסי הוא 0+1+...+(n−1) = n(n−1)/2, והסיבוכיות של קטע הקוד היא O(n²).
