# מגלים את הלוגריתם — אודי עומר

דף לימוד אינטראקטיבי בעברית ללימוד לוגריתמים וסיבוכיות זמן ריצה.

## קובץ האתר
`index.html` — גרסת המקור המאושרת.

## תהליך עבודה
- `main`: גרסה מאושרת; אין לעדכן ללא אישור מפורש.
- `draft`: ענף שינויים לבדיקה לפני אישור.
- שינויים עתידיים יבוצעו תחילה ב-`draft` וייבדקו לפני מיזוג ל-`main`.
- היסטוריית Git מאפשרת שחזור גרסאות קודמות.

## פרסום
GitHub Pages **לא הופעל** בשלב ההעלאה הראשוני. נדרשת החלטה ואישור מפורשים להפעלת פרסום לתלמידים. לאחר ההפעלה, נפרסם רק מ-`main`.

פותח על ידי אודי עומר.
